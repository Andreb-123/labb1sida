## Svar på gitfrågor

## Vad är skillnaden på gidd add och git commit?
Git add väljer vilka ändringar som är med i nästa kommit medans git commit sparar ändringarna i git.

## Varför använder man branches istället för att jobba direkt i main?
Då kan man göra ändringar sperat från main.

## Vad händer rent praktiskt när man gör en merge?
Man lägger samman ändringar med en annan branch.

## Vad är skillnaden mellan att pusha till GitHub och att publicera direkt på t.ex. Netlify?
Att pusha till github skickar projekt filerna och commits till github medans att publicera på netlify gör sidan tillgänglig på internet.

## Om du vill exkludera någon fil i projektet från versionshanteringen, hur gör du då?
Man gör en gitignore fil.
